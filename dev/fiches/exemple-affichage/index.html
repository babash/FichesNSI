Définitions

Algorithme : suite finie d’instructions permettant de résoudre un problème.

Complexité : quantité de ressources (temps, mémoire) consommées par un algorithme.

Code Python (basique)

def somme(liste):
    total = 0
    for x in liste:
        total += x
    return total


print(somme([1, 2, 3]))  # 6
