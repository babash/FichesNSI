Les Structures de Données

Les Listes (list)

  • Collection ordonnée et modifiable d'éléments.
  • Permet les doublons.
ma_liste = [1, "a", 3.14, 1]
ma_liste.append(5)
print(ma_liste[1]) # a

Les Dictionnaires (dict)

Collection non-ordonnée de paires clé-valeur. Mutable.

personne = {"nom": "Alan", "age": 41}
print(personne["nom"]) # Alan
