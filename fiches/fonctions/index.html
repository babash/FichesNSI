Les fonctions en Python

L'essentiel

Une fonction est un bloc de code nommé, qu'on écrit une fois et qu'on appelle autant de fois qu'on veut.

  • Les paramètres sont les noms écrits dans le def ; les arguments sont les valeurs données à l'appel.
  • return renvoie une valeur à l'endroit de l'appel et arrête la fonction. Sans return, la fonction renvoie None.
  • Les variables créées dans la fonction sont locales : elles n'existent pas en dehors.

Exemple

def prix_total(prix, quantite, remise=0):
    """Renvoie le prix à payer, en euros.
    prix et quantite : nombres positifs ;
    remise : pourcentage entre 0 et 100."""
    total = prix * quantite
    return total * (100 - remise) / 100

a_payer = prix_total(2.5, 4)
print(a_payer)
print(prix_total(2.5, 4, remise=10))

10.0
9.0

À l'appel prix_total(2.5, 4), le paramètre prix reçoit 2.5 et quantite reçoit 4 ; remise garde sa valeur par défaut, 0.

Spécifier et tester

La spécification (la chaîne de documentation, entre triples guillemets) dit ce que la fonction attend et ce qu'elle renvoie. Une assertion vérifie un résultat attendu : rien ne s'affiche si c'est juste, sinon AssertionError.

assert prix_total(10, 3) == 30
assert prix_total(10, 1, remise=50) == 5
print("Tests réussis")

Tests réussis

Erreurs fréquentes

  • Confondre print et return : print affiche à l'écran, return donne la valeur au programme, qui peut la ranger ou la réutiliser.
  • Écrire du code après un return : il ne s'exécute jamais.
  • Oublier les parenthèses : prix_total désigne la fonction sans l'appeler.
  • Utiliser hors de la fonction une variable locale : NameError.
  • Donner trop ou pas assez d'arguments : TypeError.
def double_affiche(x):
    print(2 * x)

r = double_affiche(5)
print(r)

10
None

La fonction affiche 10 mais ne renvoie rien : r vaut None.

À retenir

  • def nom(parametres): puis un bloc décalé.
  • Paramètre dans la définition, argument à l'appel.
  • return renvoie une valeur et termine la fonction.
  • Une fonction qui calcule renvoie ; elle n'affiche pas.
  • Spécifier avec une docstring, tester avec assert.

Exercice éclair

Qu'affiche ce programme ?

def f(n):
    if n > 10:
        return "grand"
    return "petit"
    print("fin")

print(f(12), f(3))
Réponse
grand petit : print("fin") est après le dernier return, il ne s'exécute jamais.
