Les arbres binaires de recherche

L'essentiel

Un arbre binaire de recherche (ABR) est un arbre binaire où, pour chaque nœud (les clés sont ici toutes différentes) :

  • toutes les clés du sous-arbre gauche sont plus petites que la clé du nœud ;
  • toutes les clés du sous-arbre droit sont plus grandes.

Conséquences : le parcours infixe donne les clés dans l'ordre croissant ; pour chercher une clé, on descend à gauche ou à droite, sans explorer tout l'arbre. Une recherche fait au plus h + 1 comparaisons, où h est la hauteur : h vaut environ log2(n) si l'arbre est équilibré, mais n − 1 s'il est filiforme (une seule branche).

Convention : un arbre réduit à un nœud a une hauteur 0 (l'arbre dessiné a une hauteur 2) ; d'autres sujets prennent 1 : un énoncé doit toujours la préciser.

Recherche

class Noeud:
    def __init__(self, valeur, g=None, d=None):
        self.valeur = valeur
        self.gauche = g    # sous-arbre gauche
        self.droit = d     # sous-arbre droit

def rechercher(a, v):
    if a is None:
        return False
    if v == a.valeur:
        return True
    if v < a.valeur:
        return rechercher(a.gauche, v)
    return rechercher(a.droit, v)

Chercher 9 : 9 < 12, à gauche ; 9 > 5, à droite ; trouvé en 3 comparaisons.

Insertion

def inserer(a, v):     # renvoie la racine
    if a is None:
        return Noeud(v)
    if v < a.valeur:
        a.gauche = inserer(a.gauche, v)
    else:
        a.droit = inserer(a.droit, v)
    return a

def infixe(a):
    if a is None:
        return []
    g, d = infixe(a.gauche), infixe(a.droit)
    return g + [a.valeur] + d

abr = None
for v in [12, 5, 18, 2, 9, 15]:
    abr = inserer(abr, v)
print(rechercher(abr, 9), rechercher(abr, 10))
print(infixe(abr))

True False
[2, 5, 9, 12, 15, 18]

La nouvelle clé devient toujours une feuille, à l'endroit où la recherche s'arrête.

Erreurs fréquentes

  • Vérifier la propriété avec les seuls enfants directs : si 5 avait un enfant droit 14, on aurait 14 > 5, mais 14 serait dans le sous-arbre gauche de 12 : ce n'est plus un ABR.
  • Insérer des clés déjà triées (2, 5, 9, 12…) : l'arbre devient filiforme et la recherche coûte autant qu'un parcours séquentiel.
  • Oublier de ranger le résultat : écrire inserer(abr, v) au lieu de abr = inserer(abr, v) perd l'arbre quand il est vide.

À retenir

  • À gauche plus petit, à droite plus grand, pour tous les nœuds des sous-arbres.
  • Recherche et insertion : on descend d'un seul côté à chaque nœud.
  • Coût : au plus hauteur + 1 comparaisons.
  • Parcours infixe = clés triées.

Exercice éclair

Dans l'ABR dessiné dans « L'essentiel », où va la clé 7 si on l'insère ?

Réponse
7 < 12 : à gauche ; 7 > 5 : à droite ; 7 < 9 : elle devient l'enfant gauche de 9.
