Les p-uplets (tuples) en Python

L'essentiel

Un p-uplet (type tuple) est une suite ordonnée de valeurs, écrite entre parenthèses : (12, "Sada", True). Les valeurs peuvent être de types différents.

  • On lit ses éléments par leur indice, comme une liste : t[0], t[-1].
  • Il est immuable : on ne peut ni ajouter, ni retirer, ni changer un élément.
  • Usages : des coordonnées, une date, une fonction qui renvoie plusieurs valeurs, une clé de dictionnaire.

Les opérations

Un p-uplet d'un seul élément s'écrit avec une virgule : (5,).

Exemple : renvoyer deux valeurs

def extremes(valeurs):
    return min(valeurs), max(valeurs)

notes = [12, 8, 15, 11]
resultat = extremes(notes)
print(resultat)
bas, haut = extremes(notes)
print(bas, haut)

(8, 15)
8 15

return a, b renvoie un p-uplet de deux valeurs, qu'on peut ranger dans deux variables.

Exemple : coordonnées et échange

# Mamoudzou : (latitude, longitude)
mamoudzou = (-12.78, 45.23)
latitude, longitude = mamoudzou
print(latitude)
a, b = 1, 2
a, b = b, a   # échange sans variable de plus
print(a, b)

-12.78
2 1

Les p-uplets nommés

Le programme appelle p-uplet nommé un p-uplet dont chaque élément a un nom. En Python, on l'écrit avec un dictionnaire :

eleve = {"prenom": "Faïza", "classe": "1G3",
         "age": 16}
print(eleve["classe"])

1G3

Erreurs fréquentes

  • Vouloir modifier un élément : t[0] = 10 provoque TypeError: 'tuple' object does not support item assignment.
  • Oublier la virgule : (5) est l'entier 5, pas un p-uplet.
  • Ne pas mettre autant de variables que de valeurs :
x, y = (1, 2, 3)

ValueError: too many values to unpack (expected 2)

À retenir

  • Un p-uplet : des valeurs entre parenthèses, lues par indice.
  • Il ne se modifie pas.
  • return a, b renvoie un p-uplet ; x, y = f() le déballe.
  • Un p-uplet nommé s'écrit avec un dictionnaire en Python.

Exercice éclair

Qu'affiche ce programme ?

a, b = 3, 8
a, b = b, a + b
print(a, b)
Réponse
8 11 : la partie droite (8, 3 + 8) est calculée avant l'affectation.
