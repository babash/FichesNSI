Les conditions et les boucles en Python

L'essentiel

Un bloc d'instructions suit les deux-points : et il est indenté (décalé de 4 espaces). Le bloc s'arrête à la première ligne qui n'est plus décalée.

  • Instruction conditionnelle if / elif / else : Python teste les conditions dans l'ordre et exécute un seul bloc, celui de la première condition vraie (ou le else).
  • Boucle for : répète un bloc pour chaque valeur d'une séquence. Le nombre de tours est connu. range(5) donne 0, 1, 2, 3, 4 ; range(2, 6) donne 2, 3, 4, 5 ; range(0, 10, 3) donne 0, 3, 6, 9.
  • Boucle while (« tant que ») : répète un bloc tant qu'une condition est vraie. La condition est testée avant chaque tour.

Exemple : une condition

note = 12
if note >= 16:
    print("Très bien")
elif note >= 10:
    print("Admis·e")
else:
    print("Non admis·e")
print("Fin")

Admis·e
Fin

note >= 16 est faux ; note >= 10 est vrai : son bloc s'exécute et le else est sauté. print("Fin") n'est pas décalé : il est hors du if.

Exemple : deux boucles et leur trace

total = 0
for i in range(1, 5):
    total = total + i
print(total)

n = 0
x = 1
while x < 100:
    x = x * 3
    n = n + 1
print(n, x)

10
5 243

Boucle for : total vaut 1, 3, 6 puis 10. Boucle while :

Tour12345
x < 100 ?1 : oui3 : oui9 : oui27 : oui81 : oui
x après392781243

Au 6e test, 243 < 100 est faux : la boucle s'arrête.

Erreurs fréquentes

  • Oublier les deux-points ou le décalage : SyntaxError ou IndentationError.
  • Croire que le bloc du if et celui du else s'exécutent tous les deux : un seul s'exécute.
  • Croire qu'un while s'arrête au milieu du bloc dès que sa condition devient fausse : elle n'est testée qu'au début du tour suivant (ci-dessus, x dépasse 100 et vaut 243).
  • Oublier de modifier la variable testée par le while : boucle infinie (arrêt avec Ctrl+C).
  • Décaler une ligne qui devait être après la boucle : elle s'exécute à chaque tour.
  • Remplacer un elif par un second if : le second test devient indépendant, et son bloc peut s'exécuter aussi.

À retenir

  • Un bloc : : en fin de ligne, puis 4 espaces de décalage.
  • if / elif / else : un seul bloc, celui de la première condition vraie.
  • for quand on connaît le nombre de tours, while sinon.
  • range(a, b) va de a à b - 1 : la fin n'est jamais atteinte.
  • Pour comprendre une boucle, faire sa trace : la valeur des variables à chaque tour.

Exercice éclair

Qu'affiche ce programme ?

x = 5
for k in range(3):
    if x % 2 == 0:
        x = x // 2
    else:
        x = 3 * x + 1
print(x)
Réponse
4 : 5 est impair, donne 16 ; 16 est pair, donne 8 ; 8 donne 4. Trois tours.
