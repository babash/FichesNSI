Les tableaux (listes) en Python

L'essentiel

Un tableau est une suite ordonnée de valeurs, repérées par leur indice : de 0 à len(t) - 1. En Python, c'est le type list, écrit entre crochets : [28, 31, 30].

Un tableau est modifiable (mutable) : on peut changer, ajouter ou retirer des éléments.

Les opérations

ÉcritureEffet
t[i], t[-1]l'élément d'indice i, le dernier
t[i] = vremplace l'élément d'indice i
t.append(v)ajoute v à la fin
t.insert(i, v)insère v à l'indice i
t.pop(), t.pop(i)retire le dernier élément, ou celui d'indice i, et le renvoie
len(t), v in tla taille ; True si v est présent
t[a:b]nouveau tableau, de a inclus à b exclu
[0] * 5[0, 0, 0, 0, 0]
[x * x for x in range(4)][0, 1, 4, 9] : tableau en compréhension
[x for x in t if x > 0]les éléments positifs de t

Parcourir : for x in t: (les valeurs), for i in range(len(t)): (les indices) ou for i, x in enumerate(t): (les deux).

Exemple

releves = [28, 31, 30, 33, 29]   # températures
releves.append(32)
print(len(releves), releves[0], releves[-1])
chauds = [t for t in releves if t >= 31]
print(chauds)

6 28 32
[31, 33, 32]

Tableau de tableaux (matrice)

grille = [[1, 2, 3],
          [4, 5, 6]]
print(grille[1][2], len(grille), len(grille[0]))
for ligne in grille:
    print(sum(ligne))

6 2 3
6
15

grille[1][2] : ligne d'indice 1, puis colonne d'indice 2.

Référence et copie

a = [1, 2, 3]
b = a          # b désigne LE MÊME tableau
b.append(4)
c = list(a)    # c est une copie
c.append(5)
print(a, c)

[1, 2, 3, 4] [1, 2, 3, 4, 5]

Erreurs fréquentes

  • Lire t[len(t)] : IndexError: list index out of range. Le dernier indice est len(t) - 1.
  • Croire que b = a copie le tableau (voir ci-dessus).
  • Écrire t = t.append(5) : append modifie t et renvoie None, donc t vaut None.
  • Créer une matrice avec [[0] * 3] * 2 : les deux lignes sont le même tableau. Écrire [[0] * 3 for i in range(2)].
g = [[0] * 3] * 2
g[0][0] = 9
print(g)

[[9, 0, 0], [9, 0, 0]]

À retenir

  • Indices de 0 à len(t) - 1.
  • append ajoute à la fin et modifie le tableau.
  • [expression for x in ... if condition] construit un tableau en compréhension.
  • m[i][j] : ligne i, colonne j.
  • b = a ne copie pas : list(a), a[:] ou a.copy() copie.

Exercice éclair

Qu'affiche ce programme ?

t = [5, 2, 7]
t[1] = t[0] + t[2]
t.append(t[1] * 2)
print(t)
Réponse
[5, 12, 7, 24] : t[1] devient 5 + 7 = 12, puis 24 est ajouté à la fin.
