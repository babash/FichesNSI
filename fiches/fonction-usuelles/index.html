Le parcours séquentiel d'un tableau

L'essentiel

Un parcours séquentiel examine les éléments d'un tableau un par un, du premier au dernier. Il sert à chercher une valeur, compter, calculer une somme, une moyenne, un maximum.

Une variable, l'accumulateur, garde le résultat partiel : on l'initialise avant la boucle, on la met à jour dans la boucle, on la renvoie après.

Coût linéaire : pour un tableau de n éléments, au plus n tours de boucle. Un tableau deux fois plus grand demande environ deux fois plus de temps.

Les algorithmes à savoir écrire

def maximum(t):
    m = t[0]
    for x in t:
        if x > m:
            m = x
    return m

def moyenne(t):
    s = 0
    for x in t:
        s = s + x
    return s / len(t)

def indice(t, v):
    for i in range(len(t)):
        if t[i] == v:
            return i   # trouvé : on s'arrête
    return -1          # tout parcouru : absent

pluie = [12, 0, 35, 8, 35]   # mm par jour
print(maximum(pluie), moyenne(pluie))
print(indice(pluie, 35), indice(pluie, 4))

35 18.0
2 -1

indice(pluie, 35) renvoie 2 : le premier 35 rencontré. Le return arrête la fonction, le reste du tableau n'est pas lu.

Erreurs fréquentes

  • Initialiser le maximum à 0 : faux si toutes les valeurs sont négatives. Partir de t[0].
  • Écrire return -1 dans un else à l'intérieur de la boucle : la fonction s'arrête dès le premier élément.
  • Oublier le tableau vide : t[0] provoque IndexError, s / len(t) provoque ZeroDivisionError.
  • Confondre l'indice i et la valeur t[i].
def indice_faux(t, v):
    for i in range(len(t)):
        if t[i] == v:
            return i
        else:
            return -1

print(indice_faux([12, 0, 35], 35))

-1

À retenir

  • Initialiser avant la boucle, mettre à jour dedans, renvoyer après.
  • Maximum : partir du premier élément.
  • Recherche : return dès qu'on trouve, return -1 (ou False) après la boucle.
  • Coût linéaire : proportionnel à la taille du tableau.
  • Python a max, sum et in, mais il faut savoir les écrire avec une boucle.

Exercice éclair

Que renvoie f([4, 7, 10, 3]) ? Que calcule f ?

def f(t):
    c = 0
    for x in t:
        if x % 2 == 0:
            c = c + 1
    return c
Réponse
2 : f compte les nombres pairs du tableau (4 et 10).
