Les variables et les opérateurs en Python

L'essentiel

Une variable est un nom qui désigne une valeur rangée dans la mémoire de l'ordinateur.

L'affectation x = 5 se lit « x reçoit 5 » : Python calcule d'abord la partie à droite du =, puis range le résultat dans la variable à gauche. Une variable ne garde que sa dernière valeur.

Le type vient de la valeur : int (entier, 15), float (flottant, 1.75), str (chaîne, "Sada"), bool (booléen, True ou False). La fonction type(x) le donne.

Nommer une variable

  • Lettres, chiffres et _ ; jamais de chiffre au début, ni d'espace.
  • Pas de mot réservé : if, for, class…
  • age et Age sont deux variables différentes.
  • Un nom qui dit ce qu'il contient : prix_total plutôt que p.

Les opérateurs

CalculExempleRésultat
+ - *7 * 214
division7 / 23.5 (un float)
quotient entier7 // 23
reste (modulo)7 % 21
puissance2 ** 38

Comparaisons (résultat True ou False) : == égal, != différent, <, <=, >, >=.

Logique : a and b vrai si les deux sont vrais ; a or b vrai si au moins un est vrai ; not a inverse.

Raccourcis : x += 1 veut dire x = x + 1 (de même -=, *=, /=).

Exemple et trace

a = 7
b = 2
a = a + b
b = a * 2
print(a, b)
print(a // 2, a % 2, a / 2)
print(a % 2 == 0)

Erreurs fréquentes

  • Confondre = (affecter) et == (comparer) : if x = 3: provoque SyntaxError.
  • Oublier que input() renvoie toujours une chaîne : convertir avec int(...) ou float(...).
  • Croire qu'après y = x, changer x change aussi y : non, y a reçu la valeur une fois pour toutes.
  • Attendre un calcul exact avec des flottants : 0.1 + 0.2 == 0.3 vaut False.
  • Utiliser une variable avant de lui donner une valeur : NameError.
age = input("Ton âge ? ")
print(age + 1)

Ton âge ? 15
TypeError: can only concatenate str (not "int") to str

Correction : age = int(input("Ton âge ? ")).

À retenir

  • x = expression : on calcule à droite, puis on range à gauche.
  • Une variable ne garde que sa dernière valeur.
  • / donne un float ; // le quotient entier ; % le reste.
  • Une comparaison vaut True ou False.
  • input() donne une chaîne : convertir avant de calculer.

Exercice éclair

Qu'affiche ce programme ?

x = 3
y = x
x = x + 1
print(x, y, x > y)
Réponse
4 3 True : y a reçu 3 à la ligne 2 et ne change plus quand x change.
