Les bases de données et le langage SQL

L'essentiel

Une base de données relationnelle range les données dans des relations (des tables). Chaque colonne est un attribut, avec un domaine (son type) ; chaque ligne est un enregistrement.

  • Clé primaire (soulignée) : un attribut dont la valeur identifie chaque ligne ; deux lignes ne peuvent pas avoir la même.
  • Clé étrangère (précédée de #) : un attribut qui fait référence à la clé primaire d'une autre relation.
  • Le SGBD (système de gestion de bases de données) vérifie ces contraintes et gère les accès de plusieurs personnes à la fois.

Schéma relationnel de l'exemple (données fictives) :
classe (id, nom, salle)
eleve (id, prenom, age, #id_classe)
À gauche la table eleve, à droite la table classe :

idprenomageid_classeidnomsalle
1Anli16111G1B12
2Faïza1712TG2C04
3Zaïna182
4Nassim172
5Moinécha161

Interroger : SELECT

SELECT prenom, age FROM eleve
WHERE age >= 17
ORDER BY age DESC, prenom;

prenom | age
Zaïna | 18
Faïza | 17
Nassim | 17

SELECT COUNT(*), MAX(age) FROM eleve
WHERE id_classe = 1;

COUNT(*) | MAX(age)
3 | 17

Fonctions d'agrégation : COUNT, SUM, AVG, MIN, MAX. SELECT DISTINCT age retire les doublons.

Relier deux tables : JOIN

SELECT eleve.prenom, classe.nom
FROM eleve
JOIN classe ON eleve.id_classe = classe.id
WHERE classe.salle = 'C04'
ORDER BY eleve.prenom;

prenom | nom
Nassim | TG2
Zaïna | TG2

La condition ON associe chaque élève à sa classe : clé étrangère = clé primaire.

Modifier : INSERT, UPDATE, DELETE

INSERT INTO eleve VALUES (6, 'Saïd', 15, 1);
UPDATE eleve SET age = 17 WHERE prenom = 'Anli';
DELETE FROM eleve WHERE id = 4;
SELECT COUNT(*) FROM eleve WHERE age = 17;

COUNT(*)
2

Erreurs fréquentes

  • Oublier la condition de jointure : chaque élève est associé à chaque classe (5 × 2 = 10 lignes).
  • Oublier le WHERE d'un UPDATE ou d'un DELETE : toutes les lignes sont modifiées ou supprimées.
  • Insérer une clé primaire déjà prise : UNIQUE constraint failed ; une clé étrangère sans ligne correspondante : FOREIGN KEY constraint failed.
  • Écrire les chaînes sans apostrophes : WHERE prenom = Anli cherche une colonne Anli.
  • Mettre une fonction d'agrégation dans le WHERE :
SELECT prenom FROM eleve WHERE age = MAX(age);

Erreur : misuse of aggregate function MAX()

À retenir

  • Clé primaire : identifie une ligne. Clé étrangère : référence la clé primaire d'une autre table.
  • SELECT colonnes FROM table WHERE condition ORDER BY colonne.
  • JOIN … ON clé étrangère = clé primaire.
  • INSERT INTO … VALUES, UPDATE … SET … WHERE, DELETE FROM … WHERE.

Exercice éclair

Écrire la requête qui donne le prénom des élèves de la classe 1G1, par ordre alphabétique.

Réponse
SELECT eleve.prenom FROM eleve JOIN classe ON eleve.id_classe = classe.id WHERE classe.nom = '1G1' ORDER BY eleve.prenom; (Anli, Faïza, Moinécha)
