L'écriture binaire et hexadécimale

L'essentiel

En base 10, chaque chiffre vaut une puissance de 10. En base 2 (binaire), il n'y a que deux chiffres, 0 et 1, appelés bits, et chacun vaut une puissance de 2. En base 16 (hexadécimal), seize chiffres : 0 à 9, puis A (10) à F (15).

Un octet est un groupe de 8 bits : il code les entiers de 0 à 255. Avec n bits, on code les entiers de 0 à 2n − 1. Un chiffre hexadécimal correspond à exactement 4 bits.

Puissance2726252423222120
Valeur1286432168421

De la base 2 à la base 10

On additionne les puissances de 2 sous les bits à 1 :

1011 01102 = 128 + 32 + 16 + 4 + 2 = 182

De la base 10 à la base 2

Divisions successives par 2 ; on lit les restes de bas en haut.

DivisionQuotientReste
45 ÷ 2221
22 ÷ 2110
11 ÷ 251
5 ÷ 221
2 ÷ 210
1 ÷ 201

45 = 1011012. Vérification : 32 + 8 + 4 + 1 = 45.

Base 2 et base 16

On coupe en paquets de 4 bits, en partant de la droite : 1011 0110 → 1011 = 11 = B et 0110 = 6, donc 182 = B616.

En Python

def en_binaire(n):
    if n == 0:
        return "0"
    bits = ""
    while n > 0:
        # le reste se place à gauche
        bits = str(n % 2) + bits
        n = n // 2
    return bits

print(en_binaire(45), bin(45), hex(182))
print(int("10110110", 2), int("B6", 16), 0b101101)

101101 0b101101 0xb6
182 182 45

Les préfixes 0b et 0x indiquent la base 2 et la base 16.

Erreurs fréquentes

  • Lire les restes de haut en bas : on obtient l'écriture à l'envers.
  • Croire qu'on ne peut écrire en binaire que les nombres jusqu'à 255 : 255 est la limite d'un octet ; avec plus de bits, on va plus loin.
  • Croire qu'un nombre hexadécimal contient forcément des lettres : 4216 = 66 n'en a pas. Préciser la base.
  • Commencer les paquets de 4 bits par la gauche : 101101 se coupe en 10 1101, soit 2D16.
  • Oublier qu'avec n bits le plus grand nombre est 2n − 1, et non 2n.

À retenir

  • Base 2 → base 10 : additionner les puissances de 2.
  • Base 10 → base 2 : divisions par 2, restes lus de bas en haut.
  • 1 chiffre hexadécimal = 4 bits ; 1 octet = 8 bits = 2 chiffres hexadécimaux.
  • n bits : de 0 à 2n − 1.

Exercice éclair

Écrire 2026 en hexadécimal, sachant que 2026 = 7 × 256 + 14 × 16 + 10.

Réponse
7EA16 : 7, puis 14 = E, puis 10 = A. En Python, hex(2026) donne '0x7ea'.
