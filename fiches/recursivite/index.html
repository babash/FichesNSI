La récursivité

L'essentiel

Une fonction récursive s'appelle elle-même. Elle a toujours deux parties :

  • un cas de base, résolu directement, sans appel : il arrête la récursion ;
  • un appel récursif sur un problème plus petit, qui se rapproche du cas de base.

Chaque appel a ses propres variables, comme une copie de la fonction. Les appels en attente sont rangés dans la pile d'appels : le dernier appelé est le premier à finir.

Exemple : la factorielle

n! = 1 × 2 × … × n, et 0! = 1. Donc n! = n × (n − 1)!.

def factorielle(n):
    if n == 0:                       # cas de base
        return 1
    # appel sur un problème plus petit
    return n * factorielle(n - 1)

print(factorielle(4))

24

On lit la colonne « attend » de haut en bas (la pile d'appels grandit), puis la colonne « renvoie » de bas en haut (la pile se vide).

Exemple : sur un tableau

def somme(t):
    if len(t) == 0:
        return 0
    # t[1:] : t sans son premier élément
    return t[0] + somme(t[1:])

print(somme([3, 8, 1]))

12

Erreurs fréquentes

  • Oublier le cas de base, ou un appel qui ne s'en rapproche pas (factorielle(n + 1)) : les appels s'empilent sans fin.
  • Oublier le return devant l'appel récursif : la fonction renvoie None.
  • Croire que les appels partagent la même variable n : chaque appel a la sienne.
  • Appeler avec une valeur hors du domaine prévu : factorielle(-1) ne rencontre jamais n == 0.
print(factorielle(-1))

RecursionError: maximum recursion depth exceeded

Python arrête après environ 1 000 appels en attente.

À retenir

  • Toujours écrire le cas de base en premier.
  • Chaque appel récursif doit rapprocher du cas de base : c'est ce qui assure la terminaison.
  • return devant l'appel récursif.
  • Pour comprendre, faire la trace : descente des appels, puis remontée des résultats.

Exercice éclair

Que renvoie mystere(2026) ? Que calcule cette fonction ?

def mystere(n):
    if n < 10:
        return 1
    return 1 + mystere(n // 10)
Réponse
4 : 2026, 202, 20, 2. La fonction compte les chiffres d'un entier positif.
