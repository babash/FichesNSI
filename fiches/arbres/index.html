Les arbres binaires

L'essentiel

Un arbre range des données de façon hiérarchique. Il est fait de nœuds ; le nœud du haut est la racine, un nœud sans enfant est une feuille.

Dans un arbre binaire, chaque nœud a au plus deux enfants : un sous-arbre gauche et un sous-arbre droit, éventuellement vides.

  • Taille : le nombre de nœuds.
  • Profondeur d'un nœud : le nombre d'arêtes entre la racine et lui (la racine est à la profondeur 0).
  • Hauteur : la plus grande profondeur d'un nœud, c'est-à-dire le nombre d'arêtes du plus long chemin de la racine à une feuille.

Convention de cette fiche : un arbre réduit à un nœud a une hauteur de 0 ; l'arbre vide, de −1. D'autres sujets comptent les nœuds et donnent 1 au nœud seul : un énoncé doit toujours préciser sa convention.

  • Un arbre binaire de hauteur h a au plus 2h+1 − 1 nœuds.

Exemple en Python

class Noeud:
    def __init__(self, valeur, g=None, d=None):
        self.valeur = valeur
        self.gauche = g    # sous-arbre gauche
        self.droit = d     # sous-arbre droit

def taille(a):
    if a is None:          # arbre vide
        return 0
    return 1 + taille(a.gauche) + taille(a.droit)

def hauteur(a):
    if a is None:      # convention : vide, -1
        return -1
    g = hauteur(a.gauche)
    d = hauteur(a.droit)
    return 1 + max(g, d)

def prefixe(a):
    if a is None:
        return []
    g, d = prefixe(a.gauche), prefixe(a.droit)
    return [a.valeur] + g + d

b = Noeud("B", Noeud("D"), Noeud("E"))
c = Noeud("C", None, Noeud("F"))
arbre = Noeud("A", b, c)
print(taille(arbre), hauteur(arbre))
print(prefixe(arbre))

6 2
['A', 'B', 'D', 'E', 'C', 'F']

Infixe : g + [a.valeur] + d ; suffixe : g + d + [a.valeur].

L'arbre de l'exemple et ses parcours

Racine A ; feuilles D, E, F ; taille 6 ; hauteur 2 (D, E et F sont à la profondeur 2) ; B est la racine du sous-arbre gauche.

ParcoursRègleOrdre
préfixeracine, gauche, droitA B D E C F
infixegauche, racine, droitD B E A C F
suffixegauche, droit, racineD E B F C A
en largeurniveau par niveau (avec une file)A B C D E F

Erreurs fréquentes

  • Oublier le cas de l'arbre vide : AttributeError: 'NoneType' object has no attribute 'gauche'.
  • Se tromper de convention pour la hauteur : ici un nœud seul a une hauteur 0 (et l'arbre vide −1) ; d'autres sujets prennent 1 : lire celle de l'énoncé.
  • Confondre taille (nombre de nœuds) et hauteur (nombre d'arêtes du plus long chemin).
  • Mélanger les parcours : le nom dit où est la racine : préfixe avant, infixe au milieu, suffixe après.

À retenir

  • Un arbre binaire est vide, ou un nœud avec un sous-arbre gauche et un droit.
  • Les fonctions sur les arbres sont récursives : cas de base l'arbre vide, puis appels sur les deux sous-arbres.
  • Taille = 1 + taille(gauche) + taille(droit) ; hauteur = 1 + max des deux hauteurs, avec −1 pour l'arbre vide (nœud seul : 0).
  • Largeur : une file ; profondeur (préfixe, infixe, suffixe) : la récursivité.

Exercice éclair

Donner le parcours infixe et la hauteur de cet arbre :

a = Noeud(5, Noeud(3, Noeud(1)), Noeud(8))
Réponse
Infixe : 1 3 5 8 (les valeurs sont dans l'ordre croissant : c'est un arbre binaire de recherche). Hauteur : 2 (avec la convention de la fiche : un nœud seul a une hauteur 0).
