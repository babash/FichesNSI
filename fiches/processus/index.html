Les processus et l'ordonnancement

L'essentiel

Un processus est un programme en cours d'exécution, avec sa mémoire et son numéro, le PID. Un même programme lancé deux fois donne deux processus.

Sur un cœur de processeur, un seul processus s'exécute à la fois. L'ordonnanceur du système d'exploitation les fait alterner très vite : ils semblent tourner en même temps (on parle de concurrence).

Un processus bloqué attend une ressource (une lecture de fichier, une saisie, l'imprimante) : il ne peut pas être élu avant de redevenir prêt.

Exemple : le tourniquet

Le tourniquet (round robin) donne à chaque processus prêt, à tour de rôle, un temps fixe : le quantum. Un processus pas fini retourne au bout de la file.

from collections import deque
def tourniquet(processus, quantum):
    file = deque(processus)   # (nom, durée)
    frise = []
    while len(file) > 0:
        nom, reste = file.popleft()
        for t in range(min(quantum, reste)):
            frise.append(nom) # 1 unité
        reste = reste - quantum
        if reste > 0:
            file.append((nom, reste))
    return frise

liste = [("P1", 3), ("P2", 5), ("P3", 1)]
print(" ".join(tourniquet(liste, 2)))

P1 P1 P2 P2 P3 P1 P2 P2 P2

P3 se termine au temps 5, P1 au temps 6, P2 au temps 9. D'autres ordonnancements existent : premier arrivé, premier servi ; plus court d'abord ; priorités.

L'interblocage

P1 détient la ressource R1 et attend R2 ; P2 détient R2 et attend R1. Chacun attend l'autre : aucun n'avance. C'est un interblocage (deadlock). Pour l'éviter, par exemple : demander les ressources toujours dans le même ordre.

Sous Linux

ps liste les processus et leur PID ; top les montre en temps réel ; kill 1234 arrête le processus de PID 1234.

Erreurs fréquentes

  • Confondre programme (un fichier) et processus (une exécution de ce fichier).
  • Croire que, sur un seul cœur, les processus s'exécutent vraiment en même temps : ils alternent.
  • Faire passer un processus de bloqué à élu directement : il redevient d'abord prêt.
  • Dans un exercice de tourniquet, oublier qu'un processus qui n'a pas fini va au bout de la file, derrière ceux qui attendent déjà.

À retenir

  • Processus = programme en exécution, avec un PID.
  • États : prêt, élu, bloqué (plus créé et terminé).
  • L'ordonnanceur choisit qui est élu ; tourniquet : chacun son quantum.
  • Interblocage : attente circulaire de ressources.

Exercice éclair

Mêmes processus (P1 : 3, P2 : 5, P3 : 1), tourniquet avec un quantum de 3. Dans quel ordre se terminent-ils ?

Réponse
P1 (temps 3), P3 (temps 7), P2 (temps 9). Frise : P1 P1 P1 P2 P2 P2 P3 P2 P2.
