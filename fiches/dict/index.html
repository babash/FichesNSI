Les dictionnaires en Python

L'essentiel

Un dictionnaire (type dict) associe des clés à des valeurs. On lit une valeur grâce à sa clé, jamais grâce à une position (un indice).

  • Les clés sont uniques et d'un type non modifiable : str, int, tuple.
  • Le dictionnaire est modifiable (on dit mutable) : on ajoute, change ou supprime des paires.
  • Il s'écrit entre accolades : {clé: valeur, clé: valeur}.

Les opérations

ÉcritureEffet
d = {}dictionnaire vide
d[cle]la valeur associée à cle (erreur si la clé n'existe pas)
d[cle] = vajoute la paire, ou remplace la valeur
cle in dTrue si la clé existe
d.get(cle, defaut)la valeur, ou defaut si la clé n'existe pas
del d[cle], d.pop(cle)supprime la paire (pop renvoie la valeur)
len(d)le nombre de paires
d.keys() · d.values() · d.items()les clés · les valeurs · les paires (clé, valeur)

Exemple : compter des occurrences

Combien d'élèves viennent de chaque commune ?

communes = ["Sada", "Ouangani", "Sada",
            "Bandrélé", "Sada"]
effectifs = {}
for c in communes:
    if c in effectifs:
        effectifs[c] = effectifs[c] + 1
    else:
        effectifs[c] = 1
print(effectifs)
for commune, n in effectifs.items():
    print(commune, ":", n)

{'Sada': 3, 'Ouangani': 1, 'Bandrélé': 1}
Sada : 3
Ouangani : 1
Bandrélé : 1

Trace de la boucle

Tourceffectifs après le tour
1Sada{'Sada': 1}
2Ouangani{'Sada': 1, 'Ouangani': 1}
3Sada{'Sada': 2, 'Ouangani': 1}
4Bandrélé… 'Bandrélé': 1 est ajouté
5Sada… 'Sada' passe à 3

Erreurs fréquentes

  • Lire une clé absente : effectifs["Mtsamboro"] provoque KeyError: 'Mtsamboro'. Tester "Mtsamboro" in effectifs avant, ou utiliser get.
  • Croire que d[0] donne la première paire : 0 est cherché comme une clé (KeyError: 0).
  • Prendre une liste comme clé : TypeError: unhashable type: 'list'. Utiliser un tuple.
  • Croire que for x in d parcourt les valeurs : il parcourt les clés.
  • Croire que d2 = d copie : les deux noms désignent le même dictionnaire. Copier avec d.copy().
notes = {"Anli": 12}
print(notes.get("Zaïna", "absente"))
print(notes["Zaïna"])

absente
KeyError: 'Zaïna'

À retenir

  • Une clé donne accès à sa valeur : d[cle].
  • Écrire d[cle] = v ajoute ou modifie.
  • in teste la présence d'une clé.
  • Parcourir les paires : for cle, valeur in d.items():
  • Le motif « si la clé existe, ajouter 1 ; sinon, mettre 1 » sert à compter.

Exercice éclair

Qu'affiche ce programme ?

notes = {"Anli": 12, "Faïza": 15}
notes["Anli"] = notes["Anli"] + 3
notes["Zaïna"] = 9
print(len(notes), notes["Anli"])
Réponse
3 15 : la clé "Zaïna" est ajoutée (3 paires) et la note d'Anli passe de 12 à 15.
