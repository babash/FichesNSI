Les chaînes de caractères en Python

L'essentiel

Une chaîne de caractères (type str, de l'anglais string) est une suite de caractères écrite entre guillemets : "Sada" ou 'Sada'.

  • Chaque caractère a un indice : de 0 à len(s) - 1. L'indice -1 désigne le dernier.
  • Une chaîne est immuable : on ne peut pas changer un de ses caractères. On fabrique une nouvelle chaîne.

Les opérations

Exemple : parcourir une chaîne

mot = "Mamoudzou"
print(len(mot), mot[0], mot[-1], mot[2:5])
voyelles = 0
for lettre in mot:
    if lettre in "aeiouy":
        voyelles = voyelles + 1
print(voyelles)

9 M u mou
5

Pour avoir aussi la position : for i in range(len(mot)):, puis mot[i].

Exemple : découper et recoller

phrase = "la barge part à 7h"
mots = phrase.split(" ")
print(mots)
print("-".join(mots).upper())

['la', 'barge', 'part', 'à', '7h']
LA-BARGE-PART-À-7H

Erreurs fréquentes

  • Lire après la fin : avec mot = "Mamoudzou", mot[9] provoque IndexError. Le dernier indice est len(mot) - 1.
  • Coller un nombre à une chaîne : "Total : " + 5 provoque TypeError. Écrire "Total : " + str(5) ou f"Total : {5}".
  • Croire que s.upper() modifie s : elle renvoie une nouvelle chaîne. Écrire s = s.upper().
  • Comparer des nombres écrits en chaînes : "10" < "9" vaut True (ordre alphabétique, caractère par caractère).
mot = "Sada"
mot[0] = "s"

TypeError: 'str' object does not support item assignment

Correction : mot = "s" + mot[1:].

À retenir

  • Indices de 0 à len(s) - 1 ; s[-1] est le dernier caractère.
  • s[a:b] : de a inclus à b exclu.
  • for c in s: parcourt les caractères un par un.
  • Une chaîne ne se modifie pas : on en crée une nouvelle.
  • split donne une liste, join refait une chaîne.

Exercice éclair

Qu'affiche ce programme ?

s = "NSI"
r = ""
for c in s:
    r = c + r
print(r)
Réponse
ISN : chaque caractère est ajouté devant r, ce qui retourne la chaîne.
