Les chaînes de caractères en Python

Définitions & Propriétés

  • Une chaîne est une suite de caractères entre guillemets.
  • Type immuable : on ne peut pas modifier une chaîne après sa création.
mot = "Python"
print(mot[0])  # P
mot[0] = "J"    # Erreur !

Opérations de base

s = "NSI"
print(s + " Python")
print(s * 3)
print(s[1])
