Diviser pour régner : le tri fusion

L'essentiel

La méthode diviser pour régner a trois étapes :

  1. diviser le problème en sous-problèmes plus petits, du même type ;
  2. régner : résoudre chaque sous-problème, souvent par un appel récursif ;
  3. combiner les solutions des sous-problèmes.

Le tri fusion coupe le tableau en deux moitiés, trie chaque moitié, puis fusionne les deux moitiés triées. Son coût est de l'ordre de n log2(n) : pour un million d'éléments, environ 20 millions d'opérations, contre environ 500 milliards de comparaisons pour un tri par sélection.

Le tri fusion en Python

def fusion(a, b):
    """Fusionne a et b, déjà triés."""
    resultat = []
    i, j = 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            resultat.append(a[i])
            i = i + 1
        else:
            resultat.append(b[j])
            j = j + 1
    # on ajoute ce qui reste de a ou de b
    return resultat + a[i:] + b[j:]

def tri_fusion(t):
    if len(t) <= 1:    # cas de base
        return t
    m = len(t) // 2
    gauche = tri_fusion(t[:m])
    droite = tri_fusion(t[m:])
    return fusion(gauche, droite)

print(tri_fusion([38, 27, 43, 3, 9, 82, 10]))

[3, 9, 10, 27, 38, 43, 82]

Il y a environ log2(n) niveaux, et chaque niveau de fusions coûte environ n : d'où n log2(n).

Erreurs fréquentes

  • Oublier le cas de base : RecursionError.
  • Oublier, à la fin de la fusion, les éléments qui restent dans a ou dans b : ils sont perdus.
  • Fusionner des tableaux qui ne sont pas triés : le résultat ne l'est pas non plus.
  • Couper avec len(t) / 2 : un flottant ne peut pas servir d'indice.
  • Croire que « diviser » suffit : sans l'étape « combiner », rien n'est trié.

À retenir

  • Diviser, régner (récursivement), combiner.
  • Tri fusion : couper en deux, trier les moitiés, fusionner.
  • La fusion de deux tableaux triés se fait en un seul parcours.
  • Coût en n log n, bien meilleur que n² pour les grands tableaux.
  • La recherche dichotomique est aussi un « diviser pour régner ».

Exercice éclair

Que renvoie fusion([1, 4, 9], [2, 3, 10]) ? Combien de comparaisons a[i] <= b[j] sont faites ?

Réponse
[1, 2, 3, 4, 9, 10], en 5 comparaisons ; 10 est ensuite ajouté sans comparaison.
