La programmation orientée objet

L'essentiel

Une classe définit un nouveau type : c'est le plan. Un objet (une instance) est fabriqué à partir de ce plan ; on peut en créer autant qu'on veut, chacun avec ses propres valeurs.

attributune donnée de l'objet : b1.passagers
méthodeune fonction de la classe, appelée sur un objet : b1.embarquer(120)
constructeurla méthode __init__, appelée automatiquement par Barge(...) : elle donne leur valeur de départ aux attributs
selfle premier paramètre de chaque méthode : l'objet sur lequel la méthode travaille
valeur par défautcapacite=300 : la valeur du paramètre quand l'appel ne la donne pas

L'interface d'une classe, ce sont ses méthodes : on s'en sert sans connaître son code (l'implémentation).

Exemple : une barge (fictive)

class Barge:
    def __init__(self, nom, capacite=300):
        self.nom = nom
        self.capacite = capacite
        self.passagers = 0

    def embarquer(self, n):
        if self.passagers + n <= self.capacite:
            self.passagers = self.passagers + n
            return True
        return False

    def places_libres(self):
        return self.capacite - self.passagers

b1 = Barge("Barge 1")
b2 = Barge("Barge 2", 250)
print(b1.capacite, b2.capacite)
print(b1.embarquer(120), b1.embarquer(200))
print(b1.passagers, b1.places_libres(),
      b2.passagers)

300 250
True False
120 180 0

Ce qui se passe

  1. Barge("Barge 1") crée un objet, puis appelle __init__(objet, "Barge 1", 300) : self est le nouvel objet, capacite vaut 300 par défaut.
  2. b1.embarquer(120) est traduit en Barge.embarquer(b1, 120) : 0 + 120 ≤ 300, donc 120 passagers.
  3. b1.embarquer(200) : 120 + 200 > 300, l'objet ne change pas.
  4. b2 a ses propres attributs : ses passagers restent à 0.

Erreurs fréquentes

  • Oublier self dans la définition : def places_libres(): provoque TypeError: Barge.places_libres() takes 0 positional arguments but 1 was given.
  • Oublier self. devant un attribut : return capacite - passagers provoque NameError.
  • Confondre la classe et l'objet : Barge.passagers provoque AttributeError ; c'est b1.passagers.
  • Donner une valeur à self dans l'appel : on écrit b1.embarquer(5), jamais b1.embarquer(b1, 5).
  • Croire que b3 = b1 crée un nouvel objet : b3 et b1 désignent le même.

À retenir

  • class Nom: définit le type ; Nom(...) crée un objet.
  • __init__ initialise les attributs, avec self.attribut = ....
  • Chaque méthode a self en premier paramètre, mais on ne le donne pas à l'appel.
  • Notation pointée : objet.attribut et objet.methode(...).
  • Chaque objet a ses propres valeurs d'attributs.

Exercice éclair

Qu'affiche ce programme ?

class Compteur:
    def __init__(self):
        self.valeur = 0

    def ajouter(self):
        self.valeur = self.valeur + 1

a = Compteur()
b = Compteur()
a.ajouter()
a.ajouter()
b.ajouter()
print(a.valeur, b.valeur)
Réponse
2 1 : a et b sont deux objets distincts, chacun avec son attribut valeur.
