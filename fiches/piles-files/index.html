Les piles et les files

L'essentiel

Pile (stack) : dernier entré, premier sorti (LIFO, Last In, First Out). Tout se passe au sommet.

File (queue) : premier entré, premier sorti (FIFO, First In, First Out). On enfile à la queue, on défile à la tête.

Usages. Pile : appels de fonctions, annuler, parenthésage. File : file d'attente, ordonnancement, parcours en largeur.

Interface : les opérations ; implémentation : leur code.

Pile en liste chaînée

Une cellule = (valeur, cellule suivante) ; None marque la fin.

class Pile:
    def __init__(self):
        self.haut = None    # cellule du sommet
    def est_vide(self):
        return self.haut is None
    def empiler(self, e):
        self.haut = (e, self.haut)
    def depiler(self):
        e, self.haut = self.haut
        return e

File : liste ou deux piles

Liste : append et pop(0), qui décale tout le reste.

Deux piles : défiler depuis sortie ; si elle est vide, y verser entree : le premier arrivé passe au sommet.

class File:
    def __init__(self):
        self.entree, self.sortie = [], []
    def enfiler(self, e):
        self.entree.append(e)
    def defiler(self):
        if self.sortie == []:
            while self.entree != []:
                e = self.entree.pop()
                self.sortie.append(e)
        return self.sortie.pop()
f = File()
f.enfiler("Anli")
f.enfiler("Faïza")
print(f.defiler())

Exemple tracé : le parenthésage

def bien_parenthese(texte):
    p = Pile()
    for c in texte:
        if c == "(":
            p.empiler(c)
        elif c == ")":
            if p.est_vide():
                return False
            p.depiler()
    return p.est_vide()
print(bien_parenthese("(a(b)c)"),
      bien_parenthese("(()"))

Erreurs fréquentes

  • Dépiler une pile vide : IndexError: pop from empty list avec une liste Python (TypeError avec la pile chaînée). Tester est_vide avant.
  • Défiler par pop() : on obtient le dernier arrivé.
  • Vider la pile reçue en paramètre détruit celle de l'appelant (même objet) : la reconstituer avec une pile auxiliaire.
  • Verser entree dans une sortie non vide : l'ordre est perdu.

À retenir

  • Pile : LIFO, au sommet. File : FIFO, queue et tête.
  • N'utiliser que l'interface de l'énoncé (fonctions ou méthodes p.empiler(e)) ; depiler retire, sommet lit.
  • Pile : liste Python ou liste chaînée, coût constant. File : pas de pop(0) ; deux piles ou deque.
  • Parcourir une pile sans la perdre : une pile auxiliaire.

Exercice éclair

Écrire compter(p, x), le nombre d'éléments égaux à x dans la pile p ; à la fin, p doit être comme au départ.

Réponse 
def compter(p, x):
    aux, n = Pile(), 0
    while not p.est_vide():
        e = p.depiler()
        if e == x:
            n = n + 1
        aux.empiler(e)
    while not aux.est_vide():
        p.empiler(aux.depiler())
    return n
