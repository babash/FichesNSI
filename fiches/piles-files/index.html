Les piles et les files

L'essentiel

Une pile et une file rangent des éléments les uns après les autres. Elles diffèrent par l'élément qui sort :

  • Pile (stack) : dernier entré, premier sorti (LIFO, Last In, First Out), comme une pile d'assiettes.
  • File (queue) : premier entré, premier sorti (FIFO, First In, First Out), comme une file d'attente.

L'interface

Ce sont les opérations qu'on utilise, sans savoir comment elles sont programmées (l'implémentation).

PileFileRôle
Pile()File()crée une structure vide
est_vide()est_vide()teste si elle est vide

Usages. Pile : annuler (Ctrl+Z), le bouton « précédent » du navigateur, les appels de fonctions. File : file d'impression, file d'attente, parcours en largeur d'un graphe.

Exemple : une pile

class Pile:
    def __init__(self):
        self.contenu = []
    def est_vide(self):
        return self.contenu == []
    def empiler(self, x):
        self.contenu.append(x)    # au sommet
    def depiler(self):
        return self.contenu.pop()  # le sommet

p = Pile()
for page in ["accueil", "cours", "exercice"]:
    p.empiler(page)
print(p.depiler(), p.depiler(), p.est_vide())

Exemple : une file

from collections import deque
f = deque()
for prenom in ["Anli", "Faïza", "Zaïna"]:
    f.append(prenom)              # enfiler
print(f.popleft(), f.popleft())   # défiler

Et la liste chaînée ?

Une liste chaînée (une implémentation du type abstrait liste) est une suite de cellules : chacune contient une valeur et désigne la suivante. Ajouter en tête est immédiat ; atteindre le n-ième élément demande de passer par les précédents.

class Cellule:
    def __init__(self, valeur, suivante):
        self.valeur = valeur
        self.suivante = suivante

liste = Cellule(1, Cellule(2, Cellule(3, None)))
print(liste.valeur, liste.suivante.valeur)

Erreurs fréquentes

  • Dépiler une pile vide : IndexError: pop from empty list. Tester est_vide() avant.
  • Confondre LIFO et FIFO : la pile rend le dernier arrivé, la file le premier.
  • Lire p.contenu directement : on passe par l'interface, pour pouvoir changer d'implémentation sans changer le reste du programme.
  • Confondre le type list de Python, qui est un tableau, et la liste chaînée.

À retenir

  • Pile : LIFO, empiler et dépiler au sommet.
  • File : FIFO, enfiler à la fin, défiler au début.
  • L'interface dit quoi ; l'implémentation dit comment.
  • Avant de retirer, vérifier que la structure n'est pas vide.

Exercice éclair

Sur une pile vide, on fait : empiler 1, empiler 2, empiler 3, dépiler, empiler 4, dépiler, dépiler. Quels éléments sortent, dans l'ordre ? Et avec une file (enfiler, défiler) ?

Réponse
Pile : 3, 4, 2 (il reste 1). File : 1, 2, 3 (il reste 4).
